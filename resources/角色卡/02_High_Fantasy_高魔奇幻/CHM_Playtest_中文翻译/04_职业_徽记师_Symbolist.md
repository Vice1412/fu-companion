# 徽记师 (Symbolist)

Symbolist / Calligrapher / Painter / Runemaker 徽记师/书法家/画家/符文师

徽记和图像中蕴含着巨大的力量，没有人比徽记师更了解这一点。徽记不是魔法的一门学科，而是研究如何将超自然的能量编织成标志和图标：这可能是绘画、符文、护身符等等。
大多数徽记师通过紧张的练习和细致的学习来发展他们的技能，但也有许多人将这种神奇的学科视为自由表达他们艺术愿景的一种方式。

-  什么人或事物教导你用徽记传递魔法能量的？
-  你认为你自己是施法者还是艺术家？
-  你在艺术上付出了许多练习吗？或是一个与众不同的天才？
-  你的徽记是什么样子？你如何把他们放置在生物身上？

## 🎁 免费增益 (Free Benefits)

永久提高你的IP2。


## ⚔️ 徽记师的技能


### ✦ 咒语徽记 [+3] （Magic Symbols）

如果一个盟友携带着你的徽记，他能以咒语动作来摧毁这个徽记，来施展一个你习得的咒语，只要该咒语的总MP消耗小于等于【SL*10】点。由这个盟友自己来支付MP消耗。

幻影 （Mirage）
你可以执行属于仪式学科的仪式。此外，你能以此施展能创造视觉幻象的仪式。


### ✦ 私人接触 [+5] （Personal Touch）

当一个你能看到且携带着你的徽记的生物受到伤害、恢复HP、恢复MP、同时恢复HP与MP时，你能让他相应地承受【SL】点额外伤害、额外恢复【SL】点HP、额外恢复【SL】点MP、额外同时恢复【SL】点HP与MP。

徽记链接 （Symbolic Connection）
你总能知晓任何携带着你的徽记的生物所在的方向，只要他在距离你两个旅行日的范围内。

徽记学 （Symbolism）
每次你获得本技能，你习得2种徽记。详见后文。
你最多能同时拥有【SL+1】个徽记，若你创造了多于上限的徽记，则你必须选择一个已有的徽记摧毁。
你能以使用库存动作，消耗2点IP来创造一个习得的徽记并选择：将徽记放在自己身上；将徽记放在一个可见的盟友身上；用装备着的武器进行一个自由攻击，这次攻击不会造成伤害，但能将该徽记放在所有被命中的目标身上（若命中了多个目标，每个目标都会获得一个单独计入上限的徽记复制品）。

徽记

徽记有如下基准规则：

-  一个生物最多同时携带一个徽记。如果他获得了一个新的徽记，则所有旧的徽记会被摧毁。
-  徽记的效果能持续无限久，直到被摧毁为止。
-  如果徽记师死亡，则所有他创造的徽记被摧毁。
-  如果一个生物死亡，则他所携带的徽记被摧毁。不过，若生物只是改变了自己的形态，则徽记不会被移除，因为徽记被绑定在生物本身上，而非特定的形态或肢体。
-  一个反派可以在GM场景中，消耗1点终结点来帮助他自己及同在一个场景的盟友摧毁任意数量的徽记，
-  徽记师能在任何时候摧毁任何他创造的徽记，这不需要动作。
-  如果一个徽记需要做出选择，那么需在被创造时决定，并同时被所有该徽记的复制品所继承。做出的选择不会影响在其他动作中创造的同种徽记。例如，一个徽记师选择创造弱点徽记（火），并以自由攻击命中2个生物，那么这两个生物都会获得火弱点，而之前创造过的弱点徽记（电）则不会变更为（火）。
束缚徽记：携带者的当前属性骰尺寸永远不会超过他的基础骰尺寸。这不会终止相应的提高骰尺寸的效果，只是将其无效。

制物徽记：当携带者需要在战斗中消耗IP时，他能摧毁这个徽记并无视那次IP消耗。

绝望徽记：当携带者在战斗中恢复HP或MP时，他只能恢复原本一半的数值。

命运徽记：当携带者执行一次检定后，若你能看到他，则你能消耗1点物语点，让他重投两个骰子。每个检定你只能使用本效果一次，且不能在检定结果是大成功或大失败时使用。

元素徽记：创造本徽记时，选择一项伤害类型：风 / 电 / 暗 / 土 / 火 / 冰 / 光 / 毒。当携带者对一个或多个生物造成伤害时，若你能看到携带者，你能消耗【对所有目标造成的总伤害（计入所有来源的额外伤害）/3】点MP。若如此做，则这些伤害变更为你选择的伤害类型。

憎恶徽记：只要携带者不处于危机，则任何能看到他的敌人都必须尽可能地把他选为攻击和攻击性咒语的目标（之一）。

融焊徽记：创造本徽记时，选择一项状态：眩晕 / 动摇 / 缓慢 / 虚弱。再选择一项效果：携带者获得对该状态的免疫；携带者失去对该状态的免疫，且无法重新获得对该状态的免疫。

禁止徽记：创造本徽记时，选择一项动作：攻击 / 保护 / 进行目标 / 咒语 / 技能。当携带者执行该动作时，他损失5HP和5MP。当你的角色等级达到20级时，这个数值提高至10点；达到40级时，提高至20点。

成长徽记：携带者施展的咒语若能选择“至多三个生物”作为目标，则提升至“至多四个生物”（MP消耗也会随着更多的目标而增加）。

变形徽记：创造本徽记时，选择一个种类：野兽 / 构造体 / 恶魔 / 元素 / 魔兽 / 植物 / 不死生物。携带者被视作该种类而非原本的种类（这不会改变携带者的各项数值，例如属性亲和和特殊规则等）。该徽记不能被施加给PC。

繁荣徽记：携带者使用1点物语点，来调用背景或羁绊时，他获得100泽尼特。

防护徽记：创造本徽记时，选择一项伤害类型：风 / 电 / 暗 / 土 / 火 / 冰 / 光 / 毒。携带者获得对该类型的抗性。

反抗徽记：如果一个反派在场景中，携带者进行任何对抗检定时，只要两个骰子出目相同且不是大失败，那么就视为大成功。

重生徽记：如果携带者被削减至0点HP，他能摧毁该徽记。若如此做，他被削减至1点HP作为替代。

复仇徽记：如果一个处于危机的生物用一次攻击或攻击性咒语命中了携带者，那么攻击者恢复5点HP和MP。

牺牲徽记：当携带者受到伤害时，如果你能看到他，你可以摧毁这个徽记。若如此做，你代替他受到同样数值的伤害。

巫术徽记：生物施放的咒语若选择携带者作为目标（之一），那么该咒语的总MP消耗减少5点（不低于5点）。若同时选择了多个携带者作为目标，则效果可以叠加。

真理徽记：用于研究携带者的检定、以携带者为目标的命中检定和施法检定，均获得+2加值。

弱点徽记：创造本徽记时，选择一项伤害类型：风 / 电 / 暗 / 土 / 火 / 冰 / 光 / 毒。携带者受到额外5点该类型的伤害。
