PILOT\ Biker\ Mech Pilot\ Sky Pirate

机师\ 飞车党\ 机甲驾驶员\ 天空海盗

无论是夸夸其谈的赛车手、训练有素的士兵或是举止优雅的司机，机师都与他们的爱车建立了特殊的联系——在某种程度上，它成为了他们战斗和旅行中身体的延伸。虽然在每个《最终物语Fabula Ultima》世界中都经常能看见各式各样的运输工具，但是每个机师的载具都是独一无二、不可代替的：这可能就是他们母亲曾经在战斗中驾驶的机甲、一台临时拼凑的甚至不能飞行的机械鸟或者某种科技奇迹。

- 你在哪里学习成为一名机师的?你的老师还活着吗?
- 你是如何获得你的载具的?是你自己造的？还是你继承于谁的？
- 是什么样的个性化改装让你的载具与众不同？
- 你决不允许谁或什么样的人登上你的载具？

## 🎁 免费增益 (Free Benefits)

- 你的最大HP永久提升5点。
- 你获得装备职业近战武器和职业远程武器的能力。

## ⚔️ 机师的技能

压缩技术 (COMPRESSION TECH)

如果你的个人载具不在当前场景，并且你目前所处的空间足够大到容纳你的载具，你可以执行使用库存Inventory动作花费1点IP让你的载具出现在你身边并立即免费执行进入enter载具动作。

当你的个人载具上没有人时，你可以让它立即地从现场消失。请你描述是什么样的魔法或魔科技实现了这样效果？


### ✦ 灵活配置【+4】 (FLEXIBLE CONFIGURATION)

当你驾驶你的个人载具时执行装备Equipment或者防御Guard动作时，你可以花费10点MP。如果你这样做了，你可以选择关闭至多【SL】个激活模块，再激活同等数量的关闭中模块使其转为激活状态。


### ✦ 骠勇骑兵【+4】 (MOUNTED WARRIOR)

当你驾驶你带有战马steed框架的个人载具时，你使用属于弓、火器、重型、矛和剑类型的武器进行攻击时会造成【SL+1】的额外伤害。这个效果不适用于武装模块中的武器。


### ✦ 个人载具【+6】 (PERSONAL VEHICLE)

当你获得此技能时，你将获得一辆带有你选择的框架frame和2种不同模块modules的个人载具(见下页)。

之后每当你再次获得此技能时，你将获得2个你所选择的模块。

你的载具最多只能激活【SL+2】个模块。你可以在休息时自由配置载具所有模块的激活与非激活状态。

加大油门 (STRONG GRIP)

当你使用武装模块weapon module执行命中检定时，你可以用MIG属性替换其中一个属性(例如将奥术模块变为【MIG+WLP】)

机师的载具A PILOT'S VEHICLE

机师的个人载具遵循一系列特殊规则如下:

- 进入Entering载具在冲突场景中需要采取推进目标objective动作；通常不需要检定，但如果遇到严重危险或阻碍，GM可能会引入命刻。如果冲突开始时玩家角色的载具处于可抵达范围内，他可以声明他立刻进入了载具(在《核心规则》第59页的步骤2中)。
- 离开Leaving载具不需要动作，但是在冲突期间只能在你的回合进行，在你的动作之前或之后。
- 根据载具的框架frame与模块modules，载具可以容纳不同数量的人类大小的生物。
- 任何人都可以进出载具，但只有它的机师可以驾驶载具；此外，乘客执行防御动作时无法掩护其他生物。
机师的载具总是会有一个框架frame和一系列的激活模块。标准的框架与模块将在下一页列出。

例如：你可以通过将战马Steed框架与盾模块Shied和涡轮增压模块Turbo进行组合来创建一辆装甲摩托；或者将外骨骼Exoskeleton框架与空战Aerial模块、重装镀层Heavy Plating装甲模块、步枪Rifle模块和剑Sword模块组合来创建出一台飞行动力机甲。

请注意：每当模块的文本中提到“你”时，它指的是该模块所属载具的机师。

装甲模块ARMOR MODULES

当机师驾驶着带有处于激活状态的装甲模块的载具时，机师当前的防具将被代替为载具的装甲模块而不是其原本装备的防具。如果载具没有激活装甲模块，则机师可以正常使用其装备中的防具。

- 当机师离开载具时，他们立即重新装备上其原本的防具(无需执行装备动作)。
- 在考虑角色的某些技能和效果时，标记有【职业+】符号的装甲模块会被视为一种职业防具，并将机师的物防和魔防设置为某个固定数值(盾牌与其他效果的额外加成仍然适用，就像正常的护甲一样)。请注意：机师不需要获得装备职业防具的能力就能获得载具装甲模块的好处。
例如：一个拥有守护者职业的机师可以在驾驶带有激活状态装甲模块的载具时获得防御掌握技能的好处；同时，机师将无法从游荡者的闪避技能中获得好处。

武装模块WEAPON MODULES

当机师驾驶着带有一个或更多处于激活状态的武装模块的载具时，机师无法正常使用装备在其主手和副手栏位的装备。作为替代，这些栏位被视为被载具的各种武装模块所占用。如果载具没有处于激活中的武装模块，则机师可以正常地使用其装备中的武器和盾牌。

- 当机师不再驾驶装有激活中的武装模块的载具时，他们就会立即重新装备上其原本的武器和盾牌。
- 为了角色技能或某些效果，每个武装模块都被视为单手武器（盾牌模块除外，盾牌模块将被视为盾牌）。当你设置载具的武装模块时，请声明哪个模块占据你的主手栏位，哪个模块占据你的副手栏位。
- 某些武装模块非常的笨重或复杂，使得你无法在载具上再激活其他武装模块。
例如：激活状态的斧模块的可以用来进行招架反击Counterattack技能，而步枪Rifle模块可以用来使用交叉射击Crossfire技能。

请注意：由于每个武装模块都被视为一个单手武器，机师驾驶一辆装备着两个相同类型的武装模块时可以选择进行双武器战斗——并且如果他们拥有灵巧双手Ambidextrous精通技能，则可以使用任意两种类别武装模块来进行双武器战斗。

支援模块SUPPORT MODULES

支援模块提供各种各样的杂项福利；除了机师本身，这些好处通常也适用于载具上的乘客们。

- 载具不能同时拥有2个或更多同样的支援模块。
- 某些支援模块非常复杂或笨重，在载具上激活时将被视为两个或以上激活中的模块。
损坏与修理DAMAGE AND REPAIRS

机师的载具没有自己单独的数据，并被视为机师自身的延伸或扩展。由于机师的投降，它可能会被损坏或暂时无法使用，但除非玩家同意，否则不能被摧毁。修复一台因为叙事性损毁需要等同于机师【个人载具SL×100】的zenit；另一方面，重建一台被摧毁的载具应该作为机师故事构建过程的一部分来完成(这就是为什么只有在玩家同意的情况下才应该这样做)。

作为奖励的稀有模块RARE MODULES AS REWARDS

GM应该在机师玩家的奖励中包含新模块(或现有模块的升级版).他们可以《核心规则》（从第266页开始）中设计稀有物品的规则创造这些稀有模块。

- 以下页面中的每个武装模块和装甲模块的成本都视为500zenit。此外，你不能通过选择将单手武器转变为双手武器来增加武装模块4点伤害（但你可以选择通过增加200zenit成本来增加4点伤害）
- 以下页面中的每个支援模块的成本都视为大约1000zenit。如果你支持自定义支援模块，请将其与现有的支援模块进行比较来确定其成本区间。
一般来说，机师决不应该同时拥有2个或以上同样的支援模块，也不应该装备2个或以上的效果相似或效果可累积的支援模块。

与修补匠的交互作用TINKERER INTERACTIONS

拥有修补匠职业的角色可能希望使用升级Upgrade这个英雄技能和发起造物这个规则（《核心手册》第XXX页和134页）来改进模块或为机师的载具发明全新的专属定制造物；例如，他们可能会安装一个反应堆来实现太空飞行，或者安装一个发射反魔法力场的天线。当涉及到通过发起造物来创造特殊模块时，团队作为一个整体应该确保这些模块不会挤占其他角色的优势区间和特色。给这些模块提供有限的使用次数，或者让它们包含有趣的缺陷，从而缔造出一些有趣的、难忘的场景或艰难的、有决定性的取舍，这可能是一个好主意。

支援模块清单

空战模块Aerial Module（算作2个激活模块）

载具获得飞行能力，“距离”变为×3。当你驾驶这台载具时，你的近战攻击还可以瞄准飞行中的目标；车内的所有生物都无法被近战攻击瞄准，除非攻击者正在飞行或以某种特殊方式能够瞄准到飞行目标。

当载具处于非激活状态或停飞状态时，或者当机师处于危机状态时，或者当机师执行防御Guard动作并掩护其他盟友时，该飞行效果的好处无法生效。此外，当你在冲突场景中受到风属性、电属性或冰属性伤害时，你将失去这一优势直到你下一个回合开始。

反元素模块Anti-Element Module

当你激活载具上的该模块时，选择以下一种伤害属性：风、电、土、火或冰。载具上的所有生物被视为拥有对应伤害类型的抗性。

航行模块Aquatic Module

这台载具可以在水上和水下行驶。

远程反击模块Counterstrike Module

当你驾驶中的载具上的一名角色被一次远程攻击命中后，你可以消耗1点IP。如果你这样做了，攻击者将受到10点物理伤害（在他们的攻击结算完后）。如果你达到20级或更高，这个数字提高5点伤害；如果你达到40级或更高，这个数值提高10点伤害。

挖掘模块Excavation Module

这台载具可以在地面上进行挖掘，并且配备有强力探照灯。

镀层扩展模块（仅限于战马Steed框架）Expanded Plating Module

当你驾驶着载具且其装备着一个激活中的重装、符文或标准镀层装甲模块时，这台载具上的乘客也会将他们的物防和魔防替换为该装甲模块提供的数值(如果他们本身的物防和魔防数值更高，他们仍然可以自由使用自己的正常物防和魔防数值)。

高级瞄准模块Improved Targeting Module

当你驾驶着这辆载具时，你在使用武装模块进行攻击时的命中检定+2，你施展的攻击性咒语的施法检定+2。

魔能发电模块Magistatic Module（算作2个激活模块）

当你驾驶着这辆载具并装备着奥术类武器执行咒语或技能动作后，如果其MP总消耗大于或等于5点，你恢复5点MP；如果其MP总消耗大于或等于30，则你恢复10点MP。

高出力模块Power Module

当你驾驶这台载具时，你在所有有关于暴力胁迫或物理抵抗的开放检定获得+2加值。

快接模块Rapid Interface Module

探测模块Sensor Module

涡轮增压模块Turbo Module
